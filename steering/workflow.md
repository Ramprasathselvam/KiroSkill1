# Feature Workflow

For Jira-driven iOS work, follow this order:

1. Identify Jira issue.
2. Fetch and summarize requirements.
3. Extract Figma links.
4. Inspect Figma when available.
5. Search the repository for the closest implementation and reusable components.
6. Produce a concise implementation plan.
7. Implement the smallest complete change.
8. Build and test.
9. Validate Jira acceptance criteria.
10. Validate Figma fidelity when possible.
11. Report changed files, validation results, and remaining gaps.

Do not make unrelated refactors.
