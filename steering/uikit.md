# UIKit Conventions

- Reuse the project's existing UIViewController lifecycle, storyboard/XIB, and navigation patterns.
- Search for existing table/collection layouts and reusable cells before adding new ones.
- Preserve existing Auto Layout conventions.
- Reuse existing controls, buttons, labels, and design-system views.
- Avoid unrelated storyboard or project-file changes.
- Keep controller logic consistent with the project's established ViewModel/coordinator/service pattern.
